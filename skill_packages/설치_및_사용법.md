# 7단계 제품 개발 스킬 설치·사용법

## 설치

1. `seven-stage-product-development.zip`의 압축을 풉니다.
2. 생성된 `seven-stage-product-development` 폴더를 Codex 스킬 폴더에 복사합니다.
   - macOS/Linux: `~/.codex/skills/`
   - Windows: `%USERPROFILE%\.codex\skills\`
3. Codex를 다시 시작하거나 새 작업을 엽니다.

최종 구조는 다음과 같아야 합니다.

```text
~/.codex/skills/seven-stage-product-development/SKILL.md
```

## 사용 예시

```text
$seven-stage-product-development를 사용해 재고관리 웹앱의 요구사항부터 테스트까지 7단계로 진행해 주세요.
```

```text
$seven-stage-product-development로 이 저장소의 기존 기획문서와 구현을 점검하고 누락된 단계만 보완해 주세요.
```

## 문서 골격만 생성

스킬 폴더에서 다음 명령을 실행하면 8개 문서 골격이 만들어집니다. 기존 파일은 덮어쓰지 않습니다.

```bash
python scripts/init_development_docs.py --project "프로젝트명" --owner "담당팀" --output docs/development
```

문서 작성 후 추적성 검사는 다음과 같이 실행합니다.

```bash
python scripts/validate_traceability.py --docs docs/development
```

## 적용 범위

여러 화면·기능·이해관계자가 있는 신규 소프트웨어나 웹앱에 적합합니다. 단순한 한 파일 수정이나 작은 버그 수정에는 7개 문서를 새로 만들지 않고 기존 요구사항·구현 기록·테스트만 갱신하는 방식으로 사용합니다.
